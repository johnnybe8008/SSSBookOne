# SSS Book One Staff User Manual

## Purpose

SSS Book One helps staff manage clients, folders, sessions, reports, profile details, and manual notifications from one place.

This guide is written for everyday staff users. Admin-only functions are noted separately where helpful.

## Logging In

1. Open the app in your browser or approved device.
2. Enter your email address.
3. If your account has been flagged for a password reset, the screen will switch to a new password form after your email is recognized.
4. If prompted for a reset:
   - enter your new password
   - confirm it
   - save it
   - return to the login screen and sign in with the new password
5. If no reset is required, enter your password and sign in normally.

## Home Tab

The `Home` tab gives you a quick summary of your work:

- your name and role
- billable hours for the current month
- upcoming sessions for the next 7 days
- recent sessions from the last 7 days
- a quick button to record a new session

Use this page as your daily starting point.

## Clients Tab

The `Clients` tab is where you look up and manage client records.

### What you can do

- search for clients by name or email
- filter clients by company, department, and team
- open a client profile
- add a new client

### Client records include

- contact details
- address details
- referral source
- company / department / team placement
- VIP marker when applicable

## Sessions Tab

The `Sessions` tab is where you review past work and access session details.

### What you can do

- view your own sessions
- filter by status
- open session details
- switch between full and summary view
- create a new session
- edit sessions that are still within the allowed edit window

### Edit rule

Completed sessions are only editable for a limited time. If a session is outside that window, it will show as locked.

## Recording a Session

Use `Record Session` from the Home tab or the Sessions tab.

### Basic workflow

1. Select the client.
2. Select the folder.
3. Choose session type and status.
4. Enter session timing.
5. Enter billable hours if needed.
6. Add notes.
7. Save the session.

### Scheduled sessions

If you enter a future session date/time, the session is treated as scheduled.

When notifications are active and configured, the system can queue notifications for:

- the assigned staff member
- the client

## Session Detail

The session detail page lets you review a single session in more detail.

Depending on the session status and edit window, you may also see an `Edit Session` button.

## Reports Tab

The `Reports` tab gives staff a summary of activity and billable time.

### Available information

- total sessions
- total billable hours
- average session duration
- current month progress
- recent sessions

### Filters

You can filter the report by:

- time period
- session status

Admin users may have additional filters such as staff, clients, and folders.

## More Tab

The `More` tab contains profile, notifications, app information, and logout.

### Edit Profile

Staff can update their own profile information, including:

- name
- email
- phone numbers
- address details
- notification preferences
- their own password

Non-admin staff do not see admin-only controls such as `Require Password Reset`.

### Notifications

The `Notifications` screen allows manual messages to be sent.

#### Staff users

Staff can message clients from their existing session list.

#### Admin users

Admins can message:

- clients
- staff

#### Notes

- only recipients with a mobile number are shown
- delivery uses the saved preference for each recipient
- SMS and WhatsApp delivery depend on the messaging provider configuration

### About

The `About` page shows app information and version details.

### Logout

Use `Logout` when you are finished, especially on shared devices.

## Password Rules

- passwords should be at least 6 characters long
- staff can change their own password from `More > Edit Profile`
- admins can reset a staff password from the staff edit screen
- admins can also require a password reset at next login

## Good Practice Tips

- always confirm you selected the correct client before saving a session
- use clear session notes
- double-check billable hours before saving
- log out on shared or public computers
- keep mobile numbers current if notifications are being used

## Admin-Only Functions

Admins may have access to additional areas such as:

- managing staff
- managing organizations and companies
- lookup tables
- advanced reports
- CSV import and export
- database reset tools

These are not part of the normal day-to-day staff workflow.

## Troubleshooting

### I cannot log in

- confirm your email and password
- if your account is flagged for reset, complete the password reset first
- ask an admin to confirm your account details

### I do not see a client or session

- clear filters
- check company / department / team selection
- confirm the client or session is assigned correctly

### I cannot edit a session

- the session may be outside the allowed edit window
- check whether the session is locked

### Notifications do not send

- confirm the recipient has a mobile number
- confirm the recipient has a notification preference saved
- confirm SMS / WhatsApp service is active

## Future Updates

This manual is based on the current project behavior and should be updated whenever major staff workflows change.
